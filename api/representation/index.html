    Representation Networks¶

    Coordinate-based networks that map low-dimensional inputs (positions, times) to field values — the building blocks of implicit neural representations.

    SIREN¶

    Sinusoidal representation networks (Sitzmann et al., 2020) use a sine activation, \(z_{i+1} = \sin(\omega\,(W_i z_i + b_i))\), with a frequency-aware initialisation so deep sine networks stay well-conditioned.

    siren ¶

    Sinusoidal Representation Networks (Sitzmann et al., NeurIPS 2020).

    Pure equinox.Module cores. The Bayesian SIREN wrapper that swaps each layer's W/b for pyrox_sample sites is the representative Tier-D conversion built atop these cores.

    class SirenDense(eqx.Module):
    r"""Sine-activated dense layer: ``y = sin(ω · (W x + b))`` or ``y = W x + b``.

    Single primitive of a SIREN network with three init regimes
    (Sitzmann et al. 2020, Theorem 1):

    +----------+-------------------------------------------+-------------+
    | Regime   | ``W`` init                                | Activation  |
    +==========+===========================================+=============+
    | first    | ``U(-1/d_in, 1/d_in)``                    | ``sin(ω··)``|
    +----------+-------------------------------------------+-------------+
    | hidden   | ``U(-√(c/d_in)/ω, √(c/d_in)/ω)``         | ``sin(ω··)``|
    +----------+-------------------------------------------+-------------+
    | last     | ``U(-√(c/d_in), √(c/d_in))``              | none        |
    +----------+-------------------------------------------+-------------+

    Bias ``b`` is initialised ``U(-1/√d_in, 1/√d_in)`` for every regime.

    Attributes:
        W: Weight matrix of shape ``(in_features, out_features)``.
        b: Bias vector of shape ``(out_features,)``.
        omega: Frequency multiplier applied inside the sine.
        in_features: Input dimension.
        out_features: Output dimension.
        layer_type: One of ``"first"``, ``"hidden"``, ``"last"``.
        c: Constant from Theorem 1 (default 6.0).
    """

    W: Float[Array, "in_features out_features"]
    b: Float[Array, " out_features"]
    omega: float = eqx.field(static=True)
    in_features: int = eqx.field(static=True)
    out_features: int = eqx.field(static=True)
    layer_type: SirenLayerType = eqx.field(static=True)
    c: float = eqx.field(static=True, default=6.0)

    @classmethod
    def init(
        cls,
        in_features: int,
        out_features: int,
        *,
        key: Array,
        omega: float = 30.0,
        layer_type: SirenLayerType = "hidden",
        c: float = 6.0,
    ) -> SirenDense:
        """Construct a ``SirenDense`` with Sitzmann-regime weight initialisation.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.siren import SirenDense
            >>> layer = SirenDense.init(
            ...     3, 8, key=jr.PRNGKey(0), layer_type="first"
            ... )
            >>> layer(jnp.ones(3)).shape  # (3,) -> (8,)
            (8,)
        """
        _require_positive(
            in_features=in_features,
            out_features=out_features,
            omega=omega,
            c=c,
        )
        k_w, k_b = jax.random.split(key)
        # siren_W_limit validates layer_type.
        w_limit = siren_W_limit(layer_type, in_features, omega, c)
        W = jax.random.uniform(
            k_w, (in_features, out_features), minval=-w_limit, maxval=w_limit
        )
        b_limit = 1.0 / math.sqrt(in_features)
        b = jax.random.uniform(k_b, (out_features,), minval=-b_limit, maxval=b_limit)
        return cls(
            W=W,
            b=b,
            omega=omega,
            in_features=in_features,
            out_features=out_features,
            layer_type=layer_type,
            c=c,
        )

    def __call__(self, x: Float[Array, " D_in"]) -> Float[Array, " D_out"]:
        r"""Apply the layer: ``sin(ω · (W x + b))``, or ``W x + b`` if ``last``.

        Args:
            x: Input vector of shape ``(in_features,)``.

        Returns:
            Output vector of shape ``(out_features,)``.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.siren import SirenDense
            >>> layer = SirenDense.init(4, 5, key=jr.PRNGKey(0))
            >>> layer(jnp.ones(4)).shape  # (4,) -> (5,)
            (5,)
        """
        # Affine map: (D_in,) · (D_in, D_out) -> (D_out,), then add bias.
        pre = einx.dot("i, i o -> o", x, self.W) + self.b
        if self.layer_type == "last":
            return pre  # readout layer has no activation
        # Sine activation with frequency multiplier ω: y = sin(ω · pre).
        return jnp.sin(self.omega * pre)

    class SIREN(eqx.Module):
    r"""Multi-layer sinusoidal representation network (Sitzmann et al., NeurIPS 2020).

    Topology:

    $$
    \begin{aligned}
    z_1 &= \sin(\omega_0 (W_0 x + b_0)), \\
    z_{i+1} &= \sin(\omega (W_i z_i + b_i)), \quad i = 1 \ldots L-1, \\
    y &= W_L z_L + b_L.
    \end{aligned}
    $$


    Each layer uses the corresponding Sitzmann Theorem 1 init regime
    (`SirenDense`):  ``"first"`` for layer 0, ``"hidden"`` for
    intermediate layers, and ``"last"`` for the readout.

    ``depth`` counts *all* layers including the readout; ``depth=2`` gives
    one first-layer + one last-layer (no hidden layers); ``depth=5`` gives
    first + 3 hidden + last.  Must be ≥ 2.
    """

    layers: list[SirenDense]
    in_features: int = eqx.field(static=True)
    hidden_features: int = eqx.field(static=True)
    out_features: int = eqx.field(static=True)
    depth: int = eqx.field(static=True)
    first_omega: float = eqx.field(static=True)
    hidden_omega: float = eqx.field(static=True)

    @classmethod
    def init(
        cls,
        in_features: int,
        hidden_features: int,
        out_features: int,
        *,
        depth: int,
        key: Array,
        first_omega: float = 30.0,
        hidden_omega: float = 30.0,
        c: float = 6.0,
    ) -> SIREN:
        """Construct a SIREN with the correct per-layer init regimes.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.siren import SIREN
            >>> net = SIREN.init(2, 16, 1, depth=4, key=jr.PRNGKey(0))
            >>> net(jnp.zeros(2)).shape  # (2,) -> (1,)
            (1,)
            >>> len(net.layers)  # first + 2 hidden + last
            4
        """
        if depth < 2:
            raise ValueError(f"depth must be >= 2 (first + last); got depth={depth}")
        _require_positive(
            in_features=in_features,
            hidden_features=hidden_features,
            out_features=out_features,
            first_omega=first_omega,
            hidden_omega=hidden_omega,
            c=c,
        )
        specs = build_siren_specs(
            in_features,
            hidden_features,
            out_features,
            depth,
            first_omega,
            hidden_omega,
            c,
        )
        keys = jax.random.split(key, depth)
        layers = [
            SirenDense.init(
                spec.in_features,
                spec.out_features,
                key=k,
                omega=spec.omega,
                layer_type=spec.layer_type,
                c=spec.c,
            )
            for spec, k in zip(specs, keys, strict=True)
        ]
        return cls(
            layers=layers,
            in_features=in_features,
            hidden_features=hidden_features,
            out_features=out_features,
            depth=depth,
            first_omega=first_omega,
            hidden_omega=hidden_omega,
        )

    def __call__(self, x: Float[Array, " D_in"]) -> Float[Array, " D_out"]:
        r"""Run the full forward pass, composing the sine-activated layers.

        Args:
            x: Input vector of shape ``(in_features,)``.

        Returns:
            Output vector of shape ``(out_features,)``.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.siren import SIREN
            >>> net = SIREN.init(3, 32, 2, depth=3, key=jr.PRNGKey(0))
            >>> net(jnp.ones(3)).shape  # (3,) -> (2,)
            (2,)
        """
        # z_1 = sin(ω₀(W₀x+b₀)); z_{i+1}=sin(ω(W_i z_i+b_i)); y=W_L z_L+b_L.
        # Shapes: (D_in,) -> (H,) -> … -> (H,) -> (D_out,).
        z = x
        for layer in self.layers:
            z = layer(z)
        return z

    """Return the half-width ``a`` of the ``U(-a, a)`` weight init for a SIREN layer.

    - ``"first"``:  ``a = 1 / in_features``
    - ``"hidden"``: ``a = sqrt(c / in_features) / omega``
    - ``"last"``:   ``a = sqrt(c / in_features)``

    Args:
        layer_type: One of ``"first"``, ``"hidden"``, ``"last"``.
        in_features: Input dimension of the layer.
        omega: Frequency multiplier (only affects hidden-layer limit).
        c: Constant from Theorem 1; defaults to 6.0.

    Returns:
        Half-width ``a`` such that ``W ~ U(-a, a)``.

    Raises:
        ValueError: If ``layer_type`` is not one of the three valid values.

    A single first_omega fixes the frequency band a SIREN is biased toward. MultiScaleSIREN runs \(K\) SIRENs at log-spaced first-layer frequencies and sums their readouts, \(u(x) = \sum_k \mathrm{SIREN}_k(x)\), so mixed low- and high-frequency content is covered without tuning one \(\omega_0\).

    multi_scale_siren ¶

    Multi-scale (frequency-banded) sinusoidal representation networks.

    A plain SIREN carries a single first-layer frequency \(\omega_0\), which fixes the band the network is biased toward (Rahaman et al., 2019; Wang et al., 2021). MultiScaleSIREN runs \(K\) independent SIREN sub-networks at logarithmically spaced first-layer frequencies and sums their readouts, so a signal with mixed low- and high-frequency content is covered by construction rather than by tuning one \(\omega_0\).

    The Bayesian variant — priors per band — lives downstream; this module is the deterministic core.

    $$
    u(x) = \sum_{k=1}^{K} \mathrm{SIREN}_k(x),

        r"""Sum the per-band readouts: $u(x) = \sum_k \mathrm{SIREN}_k(x)$.

        Args:
            x: Input vector of shape ``(in_features,)``.

        Returns:
            Output vector of shape ``(out_features,)``.

        Examples:
            >>> import jax, jax.numpy as jnp, jax.random as jr
            >>> from geonnax.multi_scale_siren import MultiScaleSIREN

            (10, 3)

        out = self.sub_networks[0](x)
        for sub in self.sub_networks[1:]:
            out = out + sub(x)
        return out

    degenerates to ``(omega_min,)``.

        omega_min: Lowest first-layer frequency; must be > 0.
        omega_max: Highest first-layer frequency; must be >= ``omega_min``.
        num_scales: Number of bands $K$; must be >= 1.

        [1.0, 3.162, 10.0, 31.623, 100.0]
        >>> log_spaced_omegas(30.0, 60.0, 1)  # single band -> the lower edge
        (30.0,)
    """
    if num_scales < 1:
        raise ValueError(f"num_scales must be >= 1, got {num_scales}.")
    if omega_min <= 0:
        raise ValueError(f"omega_min must be > 0, got {omega_min}.")
    if omega_max < omega_min:

            f"omega_max must be >= omega_min, got {omega_max} < {omega_min}."

    neural_field ¶

    The Bayesian Neural Field network (Saad et al., 2024) as a deterministic core.

    NeuralFieldMLP is the spatiotemporal network of Google's BayesNF without its priors: per-input learned scales, gated feature blocks (rescaled inputs, dyadic Fourier features, seasonal features of a time column, pairwise interactions and an optional pre-encoded block such as spherical-harmonic features), a learned mix of elu and tanh, NTK-scaled dense layers with learned gains, and a gained linear readout. It acts on one point (D,) -> (K,); batch with jax.vmap.

    Its named fields are the contract pyrox-nn's BayesianNeuralField swaps for NumPyro sites (Logistic(0, 1) priors in the original model): renaming one is a breaking change.

    r"""The BayesNF spatiotemporal network as a deterministic `equinox.Module`.

    For one input $x \in \mathbb{R}^D$ with fixed scales $s$ and learned
    log-scale adjustments $a$, the rescaled input is
    $\tilde x = x \oslash (s \odot e^{a})$. Feature blocks $F_k$ are built from
    it: $\tilde x$ itself, dyadic Fourier features of each column with a
    positive degree (`geonnax.basis.fourier_features`, ``rescale=True``),
    seasonal features of the **raw** time column ``x[time_col]``

    interaction products of $\tilde x$, and an optional ``extra`` block
    passed at call time (for example `SphericalHarmonicEncoder` features).

    concatenated into $h_0$. With the activation
    $\sigma_\alpha(z) = \alpha\,\mathrm{elu}(z) + (1-\alpha)\tanh(z)$,
    $\alpha = \mathrm{sigmoid}(\beta)$:

    $$
    h_{\ell+1} = \sigma_\alpha\!\Big(\mathrm{softplus}(c_\ell)\,
    \big(W_\ell^\top h_\ell / \sqrt{|h_\ell|} + b_\ell\big)\Big),
    \qquad
    y = \mathrm{softplus}(c_{\text{out}})\,
    \big(W_{\text{out}}^\top h_L / \sqrt{|h_L|} + b_{\text{out}}\big).

    makes the prior predictive fan-in independent. With ``extra=None`` the

    parameter values.

    $\mathcal{N}(0, 1)$ with the $1/\sqrt{\text{fan-in}}$ in the forward pass

    def init(
        cls,
        input_scales: tuple[float, ...],
        *,
        width: int,
        depth: int,
        out_features: int = 1,
        fourier_degrees: tuple[int, ...] = (),
        interactions: tuple[tuple[int, int], ...] = (),

        num_seasonal_harmonics: tuple[int, ...] = (),

        extra_features: int = 0,
        key: PRNGKeyArray,
    ) -> NeuralFieldMLP:
        """Build a `NeuralFieldMLP` with the deterministic default initialisation.

        Args:
            input_scales: Positive per-input scales; their number sets ``D``.
            width: Hidden width (``>= 1``).
            depth: Number of hidden layers (``>= 0``).
            out_features: Output dimension (``>= 1``).
            fourier_degrees: Per-input dyadic Fourier degrees (``>= 0``);
                empty, or one per input.
            interactions: Pairs ``(i, j)`` of input indices.
            seasonality_periods: Positive periods for seasonal features.
            num_seasonal_harmonics: Harmonics per period, same length.
            time_col: Index of the time column in ``x``.
            extra_features: Width of the ``extra`` block given at call time.
            key: PRNG key for the dense weights.

        Returns:
            A new `NeuralFieldMLP`.

        Raises:
            ValueError: On an empty or non-positive ``input_scales``, bad
                sizes, mismatched lengths, out-of-range indices, or a
                negative degree.
        """
        input_scales = tuple(float(s) for s in input_scales)
        d = len(input_scales)
        if d == 0 or any(not math.isfinite(s) or s <= 0.0 for s in input_scales):
            raise ValueError(
                f"input_scales must be non-empty and positive; got {input_scales}."
            )
        if width < 1 or depth < 0 or out_features < 1 or extra_features < 0:
            raise ValueError(
                "need width >= 1, depth >= 0, out_features >= 1, extra_features >= 0; "
                f"got {width}, {depth}, {out_features}, {extra_features}."
            )
        fourier_degrees = tuple(int(k) for k in fourier_degrees)
        if fourier_degrees and len(fourier_degrees) != d:
            raise ValueError(
                f"fourier_degrees needs one entry per input ({d}); "
                f"got {len(fourier_degrees)}."
            )
        if any(k < 0 for k in fourier_degrees):
            raise ValueError(f"fourier_degrees must be >= 0; got {fourier_degrees}.")
        interactions = tuple((int(i), int(j)) for i, j in interactions)
        if any(not (0 <= i < d and 0 <= j < d) for i, j in interactions):
            raise ValueError(
                f"interactions index outside [0, {d}); got {interactions}."
            )
        seasonality_periods = tuple(float(p) for p in seasonality_periods)
        num_seasonal_harmonics = tuple(int(h) for h in num_seasonal_harmonics)
        if len(seasonality_periods) != len(num_seasonal_harmonics):
            raise ValueError(
                "seasonality_periods and num_seasonal_harmonics need the same length; "
                f"got {len(seasonality_periods)} and {len(num_seasonal_harmonics)}."
            )
        if any(p <= 0.0 for p in seasonality_periods) or any(
            h < 0 for h in num_seasonal_harmonics
        ):
            raise ValueError(
                "periods must be > 0 and harmonics >= 0; got "
                f"{seasonality_periods} and {num_seasonal_harmonics}."
            )
        if not 0 <= time_col < d:
            raise ValueError(f"time_col must be in [0, {d}); got {time_col}.")

        block_widths = [d]
        block_widths += [2 * k for k in fourier_degrees if k > 0]
        n_seasonal = _num_seasonal_features(seasonality_periods, num_seasonal_harmonics)
        if n_seasonal > 0:
            block_widths.append(n_seasonal)
        if interactions:
            block_widths.append(len(interactions))
        if extra_features > 0:
            block_widths.append(extra_features)

        keys = jax.random.split(key, depth + 1)
        fan_in = sum(block_widths)
        layers_W, layers_b = [], []
        for k in keys[:depth]:
            layers_W.append(jax.random.normal(k, (fan_in, width)))
            layers_b.append(jnp.zeros((width,)))
            fan_in = width
        return cls(
            log_scale_adjustment=jnp.zeros((d,)),
            feature_gain=jnp.full((len(block_widths),), _UNIT_GAIN),
            logit_activation_weight=jnp.zeros(()),
            layers_W=tuple(layers_W),
            layers_b=tuple(layers_b),
            layers_gain=jnp.full((depth,), _UNIT_GAIN),
            output_W=jax.random.normal(keys[depth], (fan_in, out_features)),
            output_b=jnp.zeros((out_features,)),
            output_gain=jnp.asarray(_UNIT_GAIN),
            input_scales=input_scales,
            fourier_degrees=fourier_degrees,
            interactions=interactions,
            seasonality_periods=seasonality_periods,
            num_seasonal_harmonics=num_seasonal_harmonics,
            time_col=time_col,
            extra_features=extra_features,
            width=width,
            depth=depth,
            out_features=out_features,
        )

    def features(
        self,
        x: Float[Array, " D"],
        extra: Float[Array, " E"] | None = None,
    ) -> Float[Array, " F"]:
        """Gated, concatenated feature blocks $h_0$ for one input.

        Args:
            x: One input point, shape ``(D,)``.
            extra: Pre-encoded features, shape ``(extra_features,)``;
                required exactly when ``extra_features > 0``.

        Returns:
            $h_0$, shape ``(F,)``.

        Raises:
            ValueError: If ``x`` or ``extra`` has the wrong shape.
        """
        d = len(self.input_scales)
        if x.shape != (d,):
            raise ValueError(f"x must have shape ({d},); got {x.shape}. Use jax.vmap.")
        if (extra is None) != (self.extra_features == 0):
            raise ValueError(
                f"extra must be given exactly when extra_features > 0 "
                f"(extra_features={self.extra_features})."
            )
        if extra is not None and extra.shape != (self.extra_features,):
            raise ValueError(
                f"extra must have shape ({self.extra_features},); got {extra.shape}."
            )

        x = _promote_to_floating(x)
        scales = jnp.asarray(self.input_scales, dtype=x.dtype)
        scaled = x / (scales * jnp.exp(self.log_scale_adjustment))
        row = einx.id("d -> 1 d", scaled)

        blocks = [scaled]
        for col, k in enumerate(self.fourier_degrees):
            if k > 0:
                blocks.append(fourier_features(row[:, col], k, rescale=True)[0])
        if _num_seasonal_features(
            self.seasonality_periods, self.num_seasonal_harmonics
        ):
            t = einx.id("d -> 1 d", x)[:, self.time_col]
            blocks.append(
                seasonal_features(
                    t,
                    self.seasonality_periods,
                    self.num_seasonal_harmonics,
                    rescale=True,
                )[0]
            )
        if self.interactions:
            pairs = jnp.asarray(self.interactions, dtype=jnp.int32)
            blocks.append(interaction_features(row, pairs)[0])
        if extra is not None:
            blocks.append(extra)

        gains = jax.nn.softplus(self.feature_gain)
        return jnp.concatenate([g * b for g, b in zip(gains, blocks, strict=True)])

    def __call__(
        self,
        x: Float[Array, " D"],
        extra: Float[Array, " E"] | None = None,
    ) -> Float[Array, " K"]:
        """Evaluate the field at one point.

        Args:
            x: One input point, shape ``(D,)``.
            extra: Pre-encoded features, shape ``(extra_features,)``, when the
                model was built with ``extra_features > 0``.

        Returns:
            Field value, shape ``(out_features,)``.

        Examples:
            >>> import jax, jax.numpy as jnp, jax.random as jr
            >>> from geonnax import NeuralFieldMLP
            >>> field = NeuralFieldMLP.init(
            ...     (365.0, 180.0, 90.0), width=32, depth=2,
            ...     fourier_degrees=(0, 3, 3), seasonality_periods=(365.25,),
            ...     num_seasonal_harmonics=(2,), key=jr.PRNGKey(0),
            ... )
            >>> field(jnp.array([10.0, 3.5, 40.0])).shape
            (1,)
            >>> jax.vmap(field)(jnp.ones((8, 3))).shape
            (8, 1)
        """
        h = self.features(x, extra)
        alpha = jax.nn.sigmoid(self.logit_activation_weight)
        for W, b, c in zip(self.layers_W, self.layers_b, self.layers_gain, strict=True):
            z = jax.nn.softplus(c) * (
                einx.dot("i, i o -> o", h / jnp.sqrt(h.shape[0]), W) + b
            )
            h = alpha * jax.nn.elu(z) + (1.0 - alpha) * jnp.tanh(z)
        out = einx.dot("i, i k -> k", h / jnp.sqrt(h.shape[0]), self.output_W)
        return jax.nn.softplus(self.output_gain) * (out + self.output_b)

            f"got {width}, {depth}, {out_features}, {extra_features}."

        raise ValueError(
            f"fourier_degrees needs one entry per input ({d}); "
            f"got {len(fourier_degrees)}."

        raise ValueError(f"fourier_degrees must be >= 0; got {fourier_degrees}.")

    if any(not (0 <= i < d and 0 <= j < d) for i, j in interactions):

            f"interactions index outside [0, {d}); got {interactions}."
        )

    num_seasonal_harmonics = tuple(int(h) for h in num_seasonal_harmonics)
    if len(seasonality_periods) != len(num_seasonal_harmonics):
        raise ValueError(
            "seasonality_periods and num_seasonal_harmonics need the same length; "
            f"got {len(seasonality_periods)} and {len(num_seasonal_harmonics)}."

            "periods must be > 0 and harmonics >= 0; got "
            f"{seasonality_periods} and {num_seasonal_harmonics}."

        raise ValueError(f"time_col must be in [0, {d}); got {time_col}.")

    if n_seasonal > 0:
        block_widths.append(n_seasonal)
    if interactions:
        block_widths.append(len(interactions))
    if extra_features > 0:
        block_widths.append(extra_features)

    fan_in = sum(block_widths)
    layers_W, layers_b = [], []
    for k in keys[:depth]:

        layers_b.append(jnp.zeros((width,)))
        fan_in = width

        log_scale_adjustment=jnp.zeros((d,)),
        feature_gain=jnp.full((len(block_widths),), _UNIT_GAIN),
        logit_activation_weight=jnp.zeros(()),
        layers_W=tuple(layers_W),
        layers_b=tuple(layers_b),
        layers_gain=jnp.full((depth,), _UNIT_GAIN),
        output_W=jax.random.normal(keys[depth], (fan_in, out_features)),
        output_b=jnp.zeros((out_features,)),
        output_gain=jnp.asarray(_UNIT_GAIN),
        input_scales=input_scales,
        fourier_degrees=fourier_degrees,
        interactions=interactions,
        seasonality_periods=seasonality_periods,
        num_seasonal_harmonics=num_seasonal_harmonics,

        depth=depth,

    Args:
        x: One input point, shape ``(D,)``.
        extra: Pre-encoded features, shape ``(extra_features,)``;
            required exactly when ``extra_features > 0``.

    Returns:
        $h_0$, shape ``(F,)``.

    Raises:
        ValueError: If ``x`` or ``extra`` has the wrong shape.
    """
    d = len(self.input_scales)
    if x.shape != (d,):
        raise ValueError(f"x must have shape ({d},); got {x.shape}. Use jax.vmap.")
    if (extra is None) != (self.extra_features == 0):
        raise ValueError(
            f"extra must be given exactly when extra_features > 0 "
            f"(extra_features={self.extra_features})."
        )
    if extra is not None and extra.shape != (self.extra_features,):
        raise ValueError(
            f"extra must have shape ({self.extra_features},); got {extra.shape}."
        )

    x = _promote_to_floating(x)
    scales = jnp.asarray(self.input_scales, dtype=x.dtype)
    scaled = x / (scales * jnp.exp(self.log_scale_adjustment))
    row = einx.id("d -> 1 d", scaled)

    blocks = [scaled]
    for col, k in enumerate(self.fourier_degrees):
        if k > 0:
            blocks.append(fourier_features(row[:, col], k, rescale=True)[0])
    if _num_seasonal_features(
        self.seasonality_periods, self.num_seasonal_harmonics
    ):
        t = einx.id("d -> 1 d", x)[:, self.time_col]
        blocks.append(
            seasonal_features(
                t,
                self.seasonality_periods,
                self.num_seasonal_harmonics,
                rescale=True,
            )[0]
        )
    if self.interactions:
        pairs = jnp.asarray(self.interactions, dtype=jnp.int32)
        blocks.append(interaction_features(row, pairs)[0])
    if extra is not None:
        blocks.append(extra)

    gains = jax.nn.softplus(self.feature_gain)
    return jnp.concatenate([g * b for g, b in zip(gains, blocks, strict=True)])

    SeparableINR ¶

    Bases: Module

    A rank-\(r\) separable neural field over \(A\) input axes.

    Each axis \(a\) has a network \(\phi_a : \mathbb{R} \to \mathbb{R}^{r \times K}\), and the field is

    \[ f(x)_k = \sum_{j=1}^{r} \prod_{a=1}^{A} \phi_a(x_a)_{jk}. \]

    __call__ evaluates one point \(x \in \mathbb{R}^A\); on_grid evaluates the tensor-product grid of \(A\) one-dimensional coordinate arrays at the cost of the 1-D networks plus one contraction. A derivative along axis \(a\) only differentiates \(\phi_a\), so forward-mode jax.jvp per axis is cheap.

With SIREN axes each readout is \(O(1)\), so the field starts at \(O(\sqrt{r})\) whatever \(A\) is. With tanh MLP axes each readout is small, so the field (and its gradients) shrink geometrically with \(A\); prefer net="siren" beyond two axes.

    class SeparableINR(eqx.Module):
    r"""A rank-$r$ separable neural field over $A$ input axes.

    Each axis $a$ has a network $\phi_a : \mathbb{R} \to \mathbb{R}^{r \times K}$,
    and the field is

    $$
    f(x)_k = \sum_{j=1}^{r} \prod_{a=1}^{A} \phi_a(x_a)_{jk}.
    $$

    `__call__` evaluates one point $x \in \mathbb{R}^A$; `on_grid` evaluates
    the tensor-product grid of $A$ one-dimensional coordinate arrays at the
    cost of the 1-D networks plus one contraction. A derivative along axis $a$
    only differentiates $\phi_a$, so forward-mode `jax.jvp` per axis is cheap.

    Axis networks are `SIREN`s (``net="siren"``, the default) or tanh MLPs
    (``net="mlp"``, the SPINN paper's activation, with Equinox's default
    init), each mapping ``(1,)`` to ``(rank * out_features,)``, reshaped to
    ``(rank, out_features)``.

    Initialisation: each axis network keeps its own init (SIREN's $U(-a, a)$
    regimes via `siren_W_limit`, Equinox's default for the MLP), and the
    product is not rescaled, as in SPINN. With SIREN axes each readout is
    $O(1)$, so the field starts at $O(\sqrt{r})$ whatever $A$ is. With tanh
    MLP axes each readout is small, so the field (and its gradients) shrink
    geometrically with $A$; prefer ``net="siren"`` beyond two axes.

    Attributes:
        axis_nets: One network per axis, a tuple of length ``num_axes``.
        rank: Separation rank $r$.
        out_features: Output dimension $K$.

    References:
        Cho, J., Nam, S., Yang, H., Yun, S.-B., Hong, Y., Park, E. (2023).
        Separable physics-informed neural networks. *NeurIPS*.
    """

    axis_nets: tuple[SIREN | eqx.nn.MLP, ...]
    rank: int = eqx.field(static=True)
    out_features: int = eqx.field(static=True)

    @classmethod
    def init(
        cls,
        num_axes: int,
        rank: int,
        hidden_features: int,
        depth: int,
        out_features: int = 1,
        *,
        net: Literal["siren", "mlp"] = "siren",
        first_omega: float = 30.0,
        key: PRNGKeyArray,
    ) -> SeparableINR:
        """Build one network per axis.

        Args:
            num_axes: Number of input axes $A$ (``1 <= A <= 10``).
            rank: Separation rank $r$ (``>= 1``).
            hidden_features: Hidden width of each axis network (``>= 1``).
            depth: Layers per axis network: SIREN layers including the
                readout (``>= 2``), or MLP hidden layers (``>= 1``).
            out_features: Output dimension $K$ (``>= 1``).
            net: ``"siren"`` or ``"mlp"`` (tanh).
            first_omega: SIREN first-layer frequency; ignored for ``"mlp"``.
            key: PRNG key, split once per axis.

        Returns:
            A new `SeparableINR`.

        Raises:
            ValueError: On a size out of range or an unknown ``net``.
        """
        if not 1 <= num_axes <= len(_AXES):
            raise ValueError(f"num_axes must be in [1, {len(_AXES)}]; got {num_axes}.")
        if rank < 1 or hidden_features < 1 or out_features < 1:
            raise ValueError(
                "rank, hidden_features and out_features must be >= 1; got "
                f"{rank}, {hidden_features}, {out_features}."
            )

            raise ValueError(f"net must be 'siren' or 'mlp'; got {net!r}.")
        if net == "siren" and depth < 2:
            raise ValueError(f"a SIREN axis network needs depth >= 2; got {depth}.")
        if net == "mlp" and depth < 1:
            raise ValueError(f"an MLP axis network needs depth >= 1; got {depth}.")

        nets = []
        for k in jax.random.split(key, num_axes):
            if net == "siren":

                        1,
                        hidden_features,
                        width,
                        depth=depth,
                        first_omega=first_omega,
                        key=k,
                    )
                )

                        out_size=width,

                        depth=depth,

                        key=k,

    @property
    def num_axes(self) -> int:
        """Number of input axes $A$."""
        return len(self.axis_nets)

    def _axis_features(self, a: int, t: Float[Array, ""]) -> Float[Array, "R K"]:
        out = self.axis_nets[a](einx.id(" -> 1", t))  # (1,) -> (R·K,)
        return einx.id("(r k) -> r k", out, r=self.rank)

    def __call__(self, x: Float[Array, " A"]) -> Float[Array, " K"]:
        """Evaluate the field at one point.

        Args:
            x: One point, shape ``(num_axes,)``.

        Returns:
            Field value, shape ``(out_features,)``.

        Raises:
            ValueError: If ``x`` is not of shape ``(num_axes,)``.

        Examples:
            >>> import jax, jax.numpy as jnp, jax.random as jr
            >>> from geonnax import SeparableINR
            >>> f = SeparableINR.init(3, rank=8, hidden_features=16, depth=3,
            ...                       key=jr.PRNGKey(0))
            >>> f(jnp.array([0.1, -0.2, 0.3])).shape
            (1,)
            >>> jax.vmap(f)(jnp.zeros((5, 3))).shape
            (5, 1)
        """
        if x.shape != (self.num_axes,):
            raise ValueError(
                f"x must have shape ({self.num_axes},); got {x.shape}. Use jax.vmap "
                "for scattered points or on_grid for a tensor-product grid."
            )
        prod = self._axis_features(0, x[0])
        for a in range(1, self.num_axes):
            prod = prod * self._axis_features(a, x[a])
        return einx.sum("[r] k", prod)

    def on_grid(self, axes: tuple[Float[Array, " N"], ...]) -> Float[Array, "K *N"]:
        """Evaluate the field on the tensor-product grid of 1-D coordinates.

        Args:
            axes: ``num_axes`` one-dimensional coordinate arrays; axis ``a``
                has shape ``(N_a,)``.

        Returns:
            Field values, shape ``(out_features, N_1, ..., N_A)``.

        Raises:
            ValueError: If the number or rank of the coordinate arrays is wrong.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax import SeparableINR
            >>> f = SeparableINR.init(2, rank=4, hidden_features=8, depth=2,
            ...                       out_features=3, key=jr.PRNGKey(0))
            >>> f.on_grid((jnp.linspace(0, 1, 5), jnp.linspace(0, 1, 7))).shape
            (3, 5, 7)
        """
        if len(axes) != self.num_axes or any(c.ndim != 1 for c in axes):
            raise ValueError(
                f"axes must be {self.num_axes} one-dimensional arrays; got shapes "
                f"{[c.shape for c in axes]}."
            )
        feats = [
            jax.vmap(lambda t, a=a: self._axis_features(a, t))(c)  # (N_a, R, K)
            for a, c in enumerate(axes)
        ]
        names = _AXES[: self.num_axes]
        # Σ_r ∏_a φ_a[n_a, r, k] -> (K, N_1, ..., N_A). einx.dot contracts an
        # axis over exactly two operands, so the A-ary contraction uses einsum.
        spec = ",".join(f"{n}rk" for n in names) + f"->k{names}"
        return jnp.einsum(spec, *feats)

    Attributes:
        Omega: Frequency matrix of shape ``(out_features, in_features)``.
        phi: Phase vector of shape ``(out_features,)``.
        in_features: Input dimension.
        out_features: Output (filter) dimension.
    """

    phi: Float[Array, " out"]

    def init(
        cls,
        in_features: int,
        out_features: int,
        *,
        key: PRNGKeyArray,
        freq_scale: float = 256.0,

        out_features: Output (filter) dimension.

    Omega: Float[Array, "out in"]
    phi: Float[Array, " out"]
    mu: Float[Array, "out in"]
    log_gamma: Float[Array, " out"]
    in_features: int = eqx.field(static=True)
    out_features: int = eqx.field(static=True)
    domain: tuple[float, float] = eqx.field(static=True)

    @classmethod
    def init(
        cls,
        in_features: int,
        out_features: int,
        *,
        key: PRNGKeyArray,
        domain: tuple[float, float] = (-1.0, 1.0),
        gamma_alpha: float = 6.0,
        gamma_beta: float = 1.0,
    ) -> GaborFilter:
        """Construct with Fathony-et-al. §4.2 initialization.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.mfn import GaborFilter
            >>> g = GaborFilter.init(2, 6, key=jr.PRNGKey(0))
            >>> g(jnp.zeros(2)).shape  # (2,) -> (6,)

        _require_positive(
            in_features=in_features,
            out_features=out_features,
            gamma_alpha=gamma_alpha,
            gamma_beta=gamma_beta,

        if domain[0] >= domain[1]:

        k_gamma, k_mu, k_omega, k_phi = jax.random.split(key, 4)
        # jax.random.gamma samples Gamma(alpha, 1); divide by beta for rate=beta.
        gamma = jax.random.gamma(k_gamma, gamma_alpha, (out_features,)) / gamma_beta
        log_gamma = jnp.log(gamma)
        mu = jax.random.uniform(
            k_mu, (out_features, in_features), minval=domain[0], maxval=domain[1]
        )
        # Tied init: Omega_i ~ N(0, gamma_i * I_D).
        Omega = jax.random.normal(k_omega, (out_features, in_features)) * jnp.sqrt(
            gamma[:, None]
        )
        phi = jax.random.uniform(k_phi, (out_features,), minval=-jnp.pi, maxval=jnp.pi)
        return cls(
            Omega=Omega,
            phi=phi,
            mu=mu,
            log_gamma=log_gamma,
            in_features=in_features,

            domain=domain,

    def __call__(self, x: Float[Array, " D"]) -> Float[Array, " H"]:
        r"""Evaluate ``g(x) = sin(Ω x + φ) ⊙ exp(-γ/2 · ‖x - μ‖²)``.

        Args:
            x: Input vector of shape ``(in_features,)``.

        Returns:
            Filter response of shape ``(out_features,)``.

        Examples:
            >>> import jax.numpy as jnp, jax.random as jr
            >>> from geonnax.mfn import GaborFilter
            >>> g = GaborFilter.init(3, 4, key=jr.PRNGKey(1))
            >>> g(jnp.ones(3)).shape  # (3,) -> (4,)
            (4,)
        """
        gamma = jnp.exp(self.log_gamma)  # positivity via log-param, (H,)
        # ‖x - μ‖² = ‖x‖² + ‖μ‖² - 2 x·μ, expanded to reuse the einx dot.
        x_norm_sq = jnp.sum(x**2)  # scalar
        mu_norm_sq = jnp.sum(self.mu**2, axis=-1)  # (H,)
        cross = einx.dot("d, h d -> h", x, self.mu)  # (D,)·(H,D) -> (H,)
        sq_dist = jnp.maximum(x_norm_sq + mu_norm_sq - 2.0 * cross, 0.0)  # (H,)
        envelope = jnp.exp(-0.5 * gamma * sq_dist)  # Gaussian window, (H,)
        # Oscillation sin(Ω x + φ): (D,)·(H,D) -> (H,).
        sinusoidal = jnp.sin(einx.dot("d, h d -> h", x, self.Omega) + self.phi)
        return sinusoidal * envelope  # elementwise modulation, (H,)

    def mfn_forward(
    x: Float[Array, " D"],
    filters: Sequence[Callable[[JaxArray], JaxArray]],
    linears: Sequence[Callable[[JaxArray], JaxArray]],
) -> Float[Array, " O"]:
    """Pure-JAX MFN forward pass given user-supplied filter and linear callables.

    Implements the Fathony et al. (2021) multiplicative chaining:

    $$
    z_1 = g_1(x), \\quad
    z_{i+1} = g_{i+1}(x) \\odot (W_i z_i + b_i), \\quad
    y = W_L z_L + b_L.
    $$


    Exists as an escape hatch so users can plug custom filter families
    into the MFN topology without subclassing `FourierNet` or
    `GaborNet`.

    ``filters`` and ``linears`` must have the same length $L$.
    ``x`` is a single example of shape ``(in_features,)``; use
    `jax.vmap` for batched application.

    Examples:
        >>> import jax.numpy as jnp, jax.random as jr
        >>> from geonnax.mfn import FourierNet, mfn_forward
        >>> net = FourierNet.init(2, 4, 3, depth=2, key=jr.PRNGKey(0))
        >>> mfn_forward(jnp.zeros(2), net.filters, net.linears).shape
        (3,)
    """
    if len(filters) == 0 or len(linears) == 0:
        raise ValueError(
            f"filters and linears must be non-empty; got lengths "
            f"{len(filters)} and {len(linears)}."
        )
    if len(filters) != len(linears):
        raise ValueError(
            f"filters and linears must have equal length; got "
            f"{len(filters)} and {len(linears)}."
        )
    z = filters[0](x)  # z_1 = g_1(x): (D,) -> (H,)
    for f, lin in zip(filters[1:], linears[:-1], strict=True):
        # z_{i+1} = g_{i+1}(x) ⊙ (W_i z_i + b_i): (H,) -> (H,).
        z = f(x) * lin(z)
    return linears[-1](z)  # readout y = W_L z_L + b_L: (H,) -> (O,)

    Derivatives of fields¶

    A neural field is differentiable in its coordinates, so geostrophic velocities, elevation-change rates and PDE residuals come from automatic differentiation. geonnax.diffops turns a single-example field into its gradient, Jacobian, divergence, planar curl or Laplacian, and — for fields of a unit vector \(n \in S^2\) — its surface gradient (Cartesian or east/north) and Laplace–Beltrami operator, using the radially constant extension \(g(x) = f(x/\lVert x\rVert)\) so that \(\Delta_S f = \Delta g\) on the unit sphere.     diffops ¶

    Coordinate-derivative operators for continuous fields, flat and spherical.

    A neural field is a function of its coordinates, so its spatial derivatives come from automatic differentiation rather than finite differences. Each operator here takes a single-example field and returns a new callable that evaluates the derivative at one point; batch with jax.vmap and compile with jax.jit as usual.

    Euclidean fields of \(x \in \mathbb{R}^D\):

    • grad: \(\nabla f\), shape (D,);
    • jacobian: \(\partial u_k / \partial x_d\), shape (K, D);
    • divergence: \(\nabla \cdot u\), a scalar;
    • curl2d: \(\partial_x u_y - \partial_y u_x\), a scalar;
    • laplacian: \(\Delta f\), a scalar.

    Fields of a unit vector \(n \in S^2\) (for example a SIREN behind Cartesian3DEncoder, or SphericalHarmonicEncoder with input_mode="cartesian"):

    • surface_grad: \(\nabla_S f\), a tangent vector in Cartesian components;
    • surface_grad_enu: its east and north components at a lon/lat;
    • laplace_beltrami: \(\Delta_S f\), a scalar.

    The spherical operators act on the unit sphere. For a sphere of radius \(R\), divide surface_grad by \(R\) and laplace_beltrami by \(R^2\).

    These are operators, not losses: residual and physics costs built from them belong to the caller (vardax, pipekit).

        J = jax.jacfwd(u)(x)
        if J.shape != (2, 2):
            raise ValueError(
                f"curl2d needs u: (2,) -> (2,); got a Jacobian of shape {J.shape}."
            )
        return J[1, 0] - J[0, 1]

    return _curl

    r"""Laplacian $\Delta f = \sum_d \partial^2 f / \partial x_d^2$ of a scalar field.

    Evaluated as $\sum_d e_d^\top \nabla^2 f\, e_d$ with forward-over-reverse
    Hessian-vector products (`jax.jvp` of `jax.grad`) along the $D$ unit
    vectors, so the dense Hessian is never formed.

    Args:
        f: Scalar field of one point, ``(D,) -> ()``.

    Returns:
        A callable ``(D,) -> ()``.

    Examples:
        >>> import jax.numpy as jnp
        >>> from geonnax import diffops
        >>> lap = diffops.laplacian(lambda x: jnp.sum(x**2))
        >>> float(lap(jnp.array([0.5, -1.0, 2.0])))
        6.0
    """

    def _lap(x: Float[Array, " D"]) -> Float[Array, ""]:
        x = _check_point(x)
        g = jax.grad(f)

        def second(e: Float[Array, " D"]) -> Float[Array, ""]:
            return jnp.vdot(jax.jvp(g, (x,), (e,))[1], e)

        eye = jnp.eye(x.shape[0], dtype=x.dtype)
        return jnp.sum(jax.vmap(second)(eye))

    return _lap
