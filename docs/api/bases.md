# Spectral Bases

Deterministic feature transforms and eigenfunction bases used as inputs to, or
components of, the models above.

## Feature transforms

Fourier, seasonal, and interaction feature maps, plus standardisation helpers.

::: geonnax.basis

## Eigenfunction bases

Closed-form and graph-based eigenpairs: 1D Dirichlet/Fourier modes, real spherical
harmonics $Y_\ell^m$, Slepian functions on a cap, and graph-Laplacian ($L = D - A$)
eigenvectors.

::: geonnax._basis
